# Modelo de Landing Page com Rolagem Parallax Suave (Next.js + TailwindCSS)

Uma landing page moderna e responsiva, criada com Next.js, TailwindCSS e TypeScript, com um efeito de rolagem parallax suave e design limpo. Perfeita para lançamentos de produtos, campanhas de marketing ou apresentações de serviços.

## ✨ Recursos

- Layout em tela cheia com seção de heróis
- Transições de rolagem parallax (camadas de animação baseadas em rolagem)
- Design responsivo para dispositivos móveis
- Desenvolvido com Next.js App Router (2024+)
- TailwindCSS com configuração personalizada e animações suaves
- Interface de usuário limpa e minimalista, pronta para uso em produção

## 🛠️ Pilha de Tecnologia

- **Next.js (App Router)** – Framework React moderno com SSR e SEO
- **Tailwind CSS** – Estilo utilitário em primeiro lugar
- **TypeScript** – Componentes de segurança de tipo
- **PostCSS** – Otimização de CSS
- **Framer Motion (opcional)** – Para animações de rolagem mais suaves (se usado)
